# Контекст проекта

Игра-подарок для Саши, 9 лет, третий класс. Занимается киокушинкай в клубе КАЙТАКА (Муром), синий пояс с жёлтой полоской — это стартовый ранг героя в игре.

Главный ориентир при любых правках: **играть должно быть по силам девятилетнему**. Если выбор стоит между «интереснее взрослому» и «проходимо ребёнку» — второе.

## Правила проекта

- Никаких зависимостей. Ни фреймворков, ни сборщиков, ни npm-пакетов. Только браузерные API.
- Комментарии и текст в игре — по-русски.
- Финальный артефакт — один HTML-файл. Всё, что ломает `npm run build`, ломает подарок.
- Пиксельная графика рисуется кодом. Растровых спрайтов нет и не нужно.

## Архитектура

Состояние живёт в объекте `G` (`src/state.js`), игрок — в `P` там же. Модули импортируют их напрямую и меняют поля. Это не самый строгий подход, но для игры такого размера он проще, чем передавать состояние через аргументы.

Порядок зависимостей: `config` → `state` → `player`/`enemies` → `render/*` → `game` → `main`. `state.js` намеренно не импортирует `player.js` и модули отрисовки — иначе получится цикл. Массив `ORDER` в `build.js` повторяет этот порядок; при добавлении модуля его нужно дописать туда же.

## Грабли, на которые уже наступали

**Флаг «занят ударом» пересчитывается после обработки ввода.** В `updatePlayer` есть `wasBusy` до ввода и `busy` после. Если использовать одно значение, блок движения сбросит только что начатый удар обратно в стойку в том же кадре — удары перестанут наносить урон вообще, при этом ошибок в консоли не будет.

**Окно урона обязано лежать в фазе выпада.** Фазы считает `attackPhase()`, рисует `fighter.js`. Если сдвинуть окно в фазу замаха, враги начнут получать урон до того, как удар визуально дошёл.

**Переход к следующей волне не должен зависеть от позиции игрока.** Раньше волна появлялась только когда Саша отходил вправо. После киая, который выносит группу разом, он часто оставался стоять — и игра выглядела зависшей. Сейчас `advanceWave()` в `state.js` двигает камеру и спавнит волну сама, игрока подтягивает за собой.

**`localStorage` работает здесь, но не в артефактах Claude.ai.** Если код будет переноситься обратно в чат-артефакт, сохранение нужно отключить.

## Проверка после правок

Автотестов нет. Минимальный прогон руками:

1. `npm start`, пройти первый уровень целиком, включая босса
2. Убедиться, что удары попадают по макиварам и по живым врагам
3. Накопить дух, ударить киай, **остановиться и ничего не нажимать** — следующая волна должна прийти сама за пару секунд
4. Проиграть все жизни, проверить рестарт уровня
5. `npm run build`, открыть `dist/sasha-kyokushin.html` двойным кликом — логотип на месте, звук работает
