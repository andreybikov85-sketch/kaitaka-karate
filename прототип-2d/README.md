# САША — ПУТЬ КИОКУШИН

Браузерный beat'em'up про каратиста Сашу. Восемь уровней, от синего пояса с жёлтой полоской до чёрного. Оформление — киокушинкай, клуб КАЙТАКА, Муром.

Ни движка, ни библиотек, ни сборщика. Чистый JavaScript и canvas.

## Запуск

```bash
npm start
```

Откроется на `http://localhost:8080`. Node нужен только для локального сервера — ES-модули браузер не грузит по `file://`.

## Сборка одного файла для сына

```bash
npm run build
```

Получится `dist/sasha-kyokushin.html` — примерно 83 КБ, логотип внутри. Этот файл ни от чего не зависит: можно скинуть на флешку, отправить в мессенджере, открыть двойным кликом. Интернет не нужен.

## Структура

```
index.html            каркас страницы и экранные кнопки
server.js             локальный сервер для разработки
build.js              склейка модулей в один HTML
assets/logo.png       эмблема клуба КАЙТАКА
src/
  style.css           оформление страницы
  config.js           ПОЯСА, УРОВНИ, ТИПЫ ВРАГОВ — вся настройка здесь
  audio.js            звук, синтез через WebAudio
  input.js            клавиатура и экранные кнопки
  state.js            общее состояние G, волны, сохранение прогресса
  player.js           движение, удары, блок, киай, урон
  enemies.js          поведение врагов, снаряды, аптечки
  game.js             главный цикл, переключение экранов
  main.js             точка входа
  render/
    canvas.js         холст, шрифты, логотип, тени
    fighter.js        отрисовка бойца, фазы ударов
    background.js     фоны восьми уровней
    world.js          мир: враги, игрок, предметы, эффекты
    hud.js            панель: пояс, здоровье, дух, жизни
    screens.js        меню, заставки, вручение пояса, финал
```

## Что где менять

**Сложность.** `src/config.js` → `TYPES`: `hp` — здоровье, `dmg` — урон, `sp` — скорость, `cd` — пауза между атаками. Общий рост по уровням — функция `mul()` в `src/state.js`. Сейчас урон растёт медленнее здоровья: на первом уровне Саша держит 12–13 ударов, на восьмом — 7.

**Уровни.** `src/config.js` → `LEVELS`. Каждый уровень: название, японское имя, тема фона, волны (`[тип, количество]`), босс и подсказка. Добавить уровень — дописать запись и добавить тему в `background.js`.

**Пояса.** `src/config.js` → `BELTS`, по порядку от стартового.

**Скорость ударов.** `src/player.js`, константы `PUNCH_*` и `KICK_*`. Окно урона обязано попадать в фазу выпада (0.28–0.66 от длительности), иначе картинка разойдётся с попаданием.

## Управление

| Клавиши | Действие |
|---|---|
| стрелки или WASD | движение |
| J или Z | цуки — удар рукой |
| K или X | гери — удар ногой |
| L или C | блок |
| пробел | киай, когда шкала духа полна |
| Enter | подтверждение |
| P или Esc | пауза |

На планшете — экранные кнопки под холстом.

## Послабления для ребёнка

- Саша сам доворачивается к ближайшему противнику при ударе
- зона попадания шире силуэта, промахи «чуть мимо» не считаются
- блок гасит три четверти урона и копит дух
- таймера нет; при проигрыше рестарт уровня, а не всей игры
- пройденные уровни открываются в меню и сохраняются между запусками

## Известные особенности

Прогресс хранится в `localStorage`. В режиме инкогнито сохранение не работает — игра при этом не падает, просто каждый раз начинается с первого уровня.
