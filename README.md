# ПУТЬ КАЙТАКА

Браузерная 3D-игра про то, как ребёнок приходит в секцию карате и доходит до чёрного пояса.
Клуб киокушинкай КАЙТАКА, Муром.

## Две ссылки

| Ссылка | Что это |
|---|---|
| [**Играть**](https://andreybikov85-sketch.github.io/kaitaka-karate/v1/) — `/v1/` | Готовая версия. Заморожена, ничего не ломается. Её и давать ребёнку. |
| [Разработка](https://andreybikov85-sketch.github.io/kaitaka-karate/) — корень | Здесь идёт работа. Может не работать в любой момент — это нормально. |

Версии независимы: у каждой свой код, свои модели, своё сохранение. Правки в
корне на `/v1/` не попадают, пока её не обновят сознательно — копированием
корня в папку `v1/`. Сохранения тоже разные: боевая версия пишет в
`kaitaka-profile`, разработка — в `kaitaka-profile-dev`, чтобы сломанная
сборка не испортила прогресс ребёнка. Разработка помечена жёлтой плашкой
в углу, чтобы ссылки не путались.

Замораживать очередную версию так: скопировать `index.html`, `src`, `vendor`
и `assets` в новую папку (`v2/` и дальше), вернуть в копии ключ сохранения на
`kaitaka-profile` и убрать плашку. Старые папки не трогать — это архив,
к которому всегда можно вернуться.

## Запуск для разработки

```bash
node server.js
```

Откроется на `http://localhost:8080`. Node нужен только для локального сервера: браузер не грузит ES-модули по `file://`. В опубликованной версии сервер не участвует — раздачей занимается GitHub.

## Публикация

Игра обновляется сама при отправке изменений:

```bash
git push
```

Через минуту-две новая версия уже по ссылке. Ничего собирать не нужно.

## Что где лежит

```
v1/              замороженная боевая версия, полная копия — не править
vendor/          three.js файлом, без npm
assets/          модели персонажей, анимации, звук, эмблема клуба
src/
  core/          цикл, состояние, ввод, звук, сохранение
  scene/         рендер, камера, арены, палитра клуба
  fight/         бойцы, игрок, противники, попадания
  stages/        тренировка, кумитэ, аттестация
  ui/            интерфейс на HTML поверх 3D
  data/          пояса, техники, уровни
прототип-2d/     старая 2D-версия, справочник по боевой логике
```

## Прототип

В `прототип-2d/` лежит рабочая 2D-версия на canvas — с неё всё началось. Она не развивается, но её боевая логика проверена на живом ребёнке и переносится в 3D. Запустить: `cd прототип-2d && npm start`.
