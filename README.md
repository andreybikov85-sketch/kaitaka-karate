# ПУТЬ КАЙТАКА

Браузерная 3D-игра про то, как ребёнок приходит в секцию карате и доходит до чёрного пояса.
Клуб киокушинкай КАЙТАКА, Муром.

**Играть:** https://andreybikov85-sketch.github.io/kaitaka-karate/

## Запуск для разработки

```bash
node server.js
```

Откроется на `http://localhost:8080`. Node нужен только для локального сервера: браузер не грузит ES-модули по `file://`. В опубликованной версии сервер не участвует — раздачей занимается GitHub.

## Публикация

Игра обновляется сама при отправке изменений:

```bash
git push
```

Через минуту-две новая версия уже по ссылке. Ничего собирать не нужно.

## Что где лежит

```
vendor/          three.js файлом, без npm
assets/          модели персонажей, анимации, звук, эмблема клуба
src/
  core/          цикл, состояние, ввод, звук, сохранение
  scene/         рендер, камера, арены, палитра клуба
  fight/         бойцы, игрок, противники, попадания
  stages/        тренировка, кумитэ, аттестация
  ui/            интерфейс на HTML поверх 3D
  data/          пояса, техники, уровни
прототип-2d/     старая 2D-версия, справочник по боевой логике
```

## Прототип

В `прототип-2d/` лежит рабочая 2D-версия на canvas — с неё всё началось. Она не развивается, но её боевая логика проверена на живом ребёнке и переносится в 3D. Запустить: `cd прототип-2d && npm start`.
